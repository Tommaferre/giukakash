# GiukaKash

Web app standalone (mobile-first) per gestione personale dei soldi, pronta per GitHub Pages.

## Funzionalità

- 4 sezioni principali: **Home**, **Movimenti**, **Statistiche**, **Conti**
- Saldi calcolati automaticamente da saldo iniziale + movimenti
- Tipi movimento: entrata, uscita, trasferimento
- Filtri e ricerca sui movimenti
- Statistiche settimanali/mensili/annuali con grafico patrimonio
- Gestione categorie personalizzate
- Export/Import backup JSON
- Persistenza locale (localStorage)
- Supporto offline tramite Service Worker

## Avvio locale

Apri `index.html` nel browser.

## Deploy su GitHub Pages

Pubblica il contenuto della repository (branch principale) su GitHub Pages.
